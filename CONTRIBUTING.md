# Contributing

Thanks for your interest in improving GPT Live English Coach.

## Good contribution targets

- behavior reports from real lessons;
- persona drift or teaching-style drift;
- edge cases in the memory engine;
- improvements to onboarding and mobile usability;
- documentation clarity;
- screenshot or README presentation improvements.

## If you open an issue

Please include, when relevant:

1. instruction version;
2. profile schema version;
3. whether the issue happened in text mode or GPT Live;
4. the exact user trigger phrase;
5. what the coach actually did;
6. what you expected instead;
7. whether web search, export, or profile loading succeeded.

## If you open a pull request

- Keep the user-facing workflow simple.
- Preserve the single-file nature of the operational instruction.
- Avoid turning the project into a heavy framework unless there is a strong reason.
- If you change scheduling rules or schema semantics, update the test script.

## Scope note

This repository is centered on a polished instruction product. Please prefer changes that improve the real user experience over changes that merely add more framework structure.
